# 🌀 Maze Generator in Python With Tkinter  
![Release](https://img.shields.io/badge/Release-v1.0-blueviolet)  
![Open Source](https://badges.frapsoft.com/os/v2/open-source.svg?v=103)  

Un générateur de labyrinthes interactif développé en Python avec **Tkinter**.  
Ce programme est capable de créer des labyrinthes de manière dynamique et efficace.  

---

## 🚀 Fonctionnalités  

✔️ Génération automatique de labyrinthes  
✔️ Interface graphique avec **Tkinter**  
✔️ Algorithme optimisé pour des labyrinthes variés  
✔️ Génération en boucle pour une exploration continue

## 📌 Prérequis  

Avant d'exécuter le programme, assurez-vous d'avoir **Python 3.x** installé sur votre machine.  
Vous pouvez vérifier votre version de Python avec :  

```
python --version
```

Installez également **Tkinter** si ce n'est pas déjà fait :  

```
pip install tk
```

---

## 🛠️ Installation et Exécution  

Clonez le projet depuis GitHub :  

```
git clone https://github.com/Yannise-A/Maze_Generator.git
cd Maze_Generator
```

Lancez le programme :  

```
python maze_generator.py
```

---

## 🔍 Fonctionnement  

Le programme utilise un **algorithme de génération de labyrinthes** et affiche le résultat dans une interface Tkinter.  
Il est conçu pour **générer des labyrinthes en boucle**, permettant d'explorer différentes structures à l'infini.
